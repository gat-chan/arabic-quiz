# アラビア数字クイズ Webアプリ
エジプト旅行に行く際に作りました
アラビア数字を認識し、変換する練習を行うことができるアプリケーションです。クイズモードとアラビア数字の入力を変換するツールが特徴です。

## 機能

### 1. **クイズモード**
   - **初級編**：簡単なアラビア数字を認識する問題（選択肢2つ）。
   - **中級編**：簡単なアラビア数字を認識する問題（選択肢10個）。
   - **上級編**：もっと複雑な数字（実装予定）。
   - **玄人編**：最も難しい数字（実装予定）。

### 2. **変換ツール**
   - アラビア数字をアラビア語の数字に変換します（例：'123' → '١٢٣'）。
   - アラビア数字を入力すると、自動的に変換されます。

## 使用技術

- **HTML5**：構造
- **CSS3**：スタイリング
- **JavaScript**：機能
- **Google Fonts**：カスタムフォント
